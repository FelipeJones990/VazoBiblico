# Vazo Bíblico 🏺

Projeto web desenvolvido como uma experiência interativa baseada na
Parábola do Semeador.

## 🎯 Objetivo

Criar uma experiência interativa para apresentar a mensagem da
Parábola do Semeador de forma visual e dinâmica.

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript
- GitHub Pages

## ✨ Funcionalidades

- Página inicial temática
- Experiência interativa
- Sistema de pontuação
- Interação com palavras positivas e negativas
- Seleção de versículos
- Layout responsivo
